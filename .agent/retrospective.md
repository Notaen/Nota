# Retrospective

Past session lessons. Read to avoid repeating mistakes.

## Mistakes to Avoid
- Don't replace existing types when the user says "add" — keep both.
- Don't auto-add defaults (persona, user, etc.) unless explicitly requested.
- Don't over-engineer minimal asks (e.g. creating a file ≠ building a CRUD manager).
- Don't hardcode names that should come from filesystem config.
